⚖️ Section 4 — Why These Models? (Judge Explanation)

Every production model was selected strictly based on measured validation set performance within our predefined candidate suite:

Module A @ 24h: Logistic Regression (Balanced)
Selected for highest Class 1 Recall (70.0% Val) and lowest FNR (30.0% Val) under early noisy sensor conditions.
Module A @ 96h: Random Forest Classifier
Selected for superior non-linear separation (95.56% Val Recall, 0.9953 Val ROC-AUC) on multi-point drift metrics.
Module B @ 24h: Gradient Boosting Regressor
Selected for lowest validation RMSE (0.0416) and best noise resilience over linear baselines ($R^2 = 0.768$ vs $0.380$).
Module B @ 96h: Random Forest Regressor
Selected for lowest validation RMSE (0.0133) and highest explanation of physical degradation variance ($R^2 = 0.976$).

🛡️ Section 5 — Temporal Leakage Protection

Strict physical and temporal safeguards prevent future contamination and data snooping:

24h Screening Gate: Uses ONLY 0h + 24h measurements (11 features). 96h and 168h data are strictly excluded.
96h Screening Gate: Uses ONLY 0h + 24h + 96h measurements (19 features). 168h data is strictly excluded.
Target Isolation: Ground truth labels (module_a_label, iddq_drift_168h_true) are isolated to $y$. Never in $X$.
Component-Level Partition: 7,000 Train / 1,500 Val / 1,500 Test with ZERO component ID overlap.

💬 Judge Q&A Quick Reference

Concise, mathematically grounded answers to common jury defense questions.

❓ 1. What models did you use and why?
We evaluated linear models, tree bagging, and sequential gradient boosting on a strictly held-out validation set. For Module A, Logistic Regression (Balanced) was selected at 24h for optimal sensitivity under noisy conditions, and Random Forest Classifier at 96h for non-linear multi-drift separation. For Module B, Gradient Boosting Regressor was selected at 24h and Random Forest Regressor at 96h based on lowest measured validation RMSE.
❓ 2. What features enter the model at 24h vs 96h?
At 24h, only 11 features are admitted (5 pre-stress 0h baselines, 5 raw 24h readings, and 24h percentage drift in $I_{DDQ}$). At 96h, 19 features are admitted (all 24h features + 5 raw 96h readings + 3 multi-parameter drift rates in $I_{DDQ}$, leakage, and delay). 168h measurements are NEVER used as input features.
❓ 3. Why does 96h screening significantly outperform 24h?
At 24h, latent defects have only accumulated $+1.45\%$ mean drift, overlapping heavily with thermal noise (Cohen's $d = 0.457$). By 96h ($72\text{h}$ additional stress), degradation diverges to $+5.07\%$ for drifting components and $+17.98\%$ for anomalous units (Cohen's $d = 1.522$), sharply elevating signal-to-noise ratio and boosting defect recall to $94.00\%$.
❓ 4. How did you guarantee zero target and temporal data leakage?
We enforced three structural guarantees: (1) Component-level splitting (7,000 Train / 1,500 Val / 1,500 Test) with 0 component ID overlap; (2) Gate-specific feature masking preventing 96h/168h data in early models; (3) Preprocessors (SimpleImputer and StandardScaler) fitted strictly on the Training set.
❓ 5. Are predictions based on real data or synthetic shortcuts?
All predictions come directly from serialized production models evaluated on genuine test components. Furthermore, our controlled feature ablation study proved that raw multi-point measurements natively provide $80.89\%$ recall, and engineered drift features add $13.11\%$ extra capture—confirming genuine physical degradation dynamics.
